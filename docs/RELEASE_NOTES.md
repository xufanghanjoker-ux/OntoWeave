# OntoWeave 发布说明

## v0.2.0-alpha.2

- 导入后自动进入已发布的实例图。可在同一个版本内从本体定义定位实例，从实例返回定义，也可按文件名或正文搜索资料并定位原文。
- 人工处理更新发布后，可以对照处理前后，并定位图中实际变化。
- PostgreSQL 保存问答会话、回答、引用与续聊状态。本版取消从旧 SQLite 导入问答会话。

[安装和启动指南](GETTING_STARTED.md)

## v0.2.0-alpha.1

新版把资料上传、图谱、本体、知识纠错和引用问答整合到一个工作台，使用 PostgreSQL 和 pgvector 保存知识版本及检索索引。

- 可以新建、切换、重命名工作空间，移到回收站后恢复。
- 可以在同一空间追加、替换和移出资料，从目录打开正文或下载原件。新图谱与索引确认后一起切换，历史图和已保存引用可回查。
- 支持通过对象、关系和来源浏览图谱，预览人工纠错的影响，并在应用后查看变化。
- 保留三栏问答、流式 Markdown 和引用预览，可从已有引用返回原文或同版图中关系。

使用前请阅读[安装和启动指南](GETTING_STARTED.md)。旧 SQLite 空间保留在旧版运行目录，本版使用独立 PostgreSQL，无自动迁移。

本版仍为 macOS 本机单用户预览。模型生成与知识覆盖依赖输入和模型输出，建议通过原文引用核对关键结论。行动反馈、外部 Agent 接入和预测能力仍在建设。

在 macOS Apple Silicon 的独立源码目录中完成了锁定依赖安装、Rust 构建、公开 Codex CLI 协议验证和空 PostgreSQL 启动。合成 Markdown 经产品入口完成图谱与索引发布，并获得带来源的模拟问答。独立解析环境使用已有权重缓存，通过合成 Word、PDF 和扫描 PDF 验证。公开源码包的验收使用本地模型响应夹具，真实模型能力以实际手测为准。

## v0.1.0-alpha.1

状态：源码Alpha预发布。采用Apache-2.0。旧LightOG/CQForge内部标识保留兼容。

包含资料解析、分块、CQ、按需归族、Codex语义抽取、程序保存与推进、图索引、引用问答和双时间读取基础。

已知限制：抽取和图覆盖仍不稳定；实体、字面值、事件及限定可能组织不完整；文本或未绑定值不代表结构可答。程序主导抽取已实施，但还需新工作空间真人验收。未完成跨平台安装、生产权限、多租户或不可信上传安全验收。Codex版本兼容受限。

首发阻断检查：干净目录安装、Rust构建、解析环境准备、原生Codex协议及空工作空间启动；发布目录秘密扫描、资料排除、第三方许可核查；GitHub仓库和CLI授权。未完成项不能表述为已通过。

发布不包含业务资料、公共基准原文与答案、测试数据库、历史本机报告、模型权重或密钥。研究设计及局部测试不作为完整产品交付证据。
