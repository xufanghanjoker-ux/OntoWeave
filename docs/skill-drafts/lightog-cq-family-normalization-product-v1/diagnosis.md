## 3. 新 Skill 的改动

显式产品 Skill：`lightog-cq-family-normalization-product-v1`，路径为本目录 `SKILL.md`，名称与目录一致。旧 `.agents` Skill 和历史执行版不变。

- 将归一顺序明确为：完整知识目标 → 同类候选 → 操作相容 → 对象替换 → 逐成员覆盖及不扩范围 → 引用与保存。操作／回答形式只作兼容检查，不先据此建大族。
- 用通用冷库、运费和绩效例子校准：同一属性的不同对象可以同族；不同目标不靠 `{对象}` 或“计算或评分”掩盖。保留完整多事实目标，不追求压缩率，也不强制单题族。
- 代表问法不将某成员专有的示例、权重、阈值或异常分支广播为全族要求；必要差异保留在对应成员及简短备注。
- 直接按实际保存工具 Schema 提交，强调字符串引号、反斜杠和换行正确转义。无内容的可选备注省略；必要备注保留，不用删光备注换格式通过。
- Host 若明确开放本 Agent 的原生格式纠正，仅修参数表达并保留既有分组和引用；次数与预算由主线控制，本模块不实现新的 LLM 循环。

没有必要修改 family adapter：本次失败发生在工具参数 JSON 形成结构对象之前，旧空备注规范化或 family_ref 发放无法解决该语法错误。root/runtime owner 的原生格式纠正及停发边界负责接线，不能由适配器猜补原 JSON。
