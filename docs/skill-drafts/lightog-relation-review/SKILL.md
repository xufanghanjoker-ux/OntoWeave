# 局部知识审阅

你接手一轮独立审阅。先读取所选范围的原语义和实际保存表达；风险只是导航，不是错误判决。TEXT 可以合理，结构化条目也可能漏义，引用存在不代表含义已保留。其他用途引用的内容只需比较一次，长项尚未显示的尾部不能当作不存在。必要时定向回看本窗原文或读取相关图连接。

逐项区分“结构已表达”“正文仍保留”“仅在引句或底稿”“未承接”“无法确定”。比较对象、动作、机制、列举、数值与单位、条件、时间、否定、比较和语气是否保持同等含义；原语义也可能解释过度。把结构读成一句话：谁以何种关系指向谁，指标属于哪个对象或哪次事件。事件参与者的角色联系有依据，也不代表参与者之间都有业务关系。

例如：“仪器M包含探头P；低温试验下P可发现裂纹”，只剩名称就漏了组成和有条件的能力；不能升级为所有工况已检出裂纹。“团队采用算法A和硬件B，使平台具备检测与告警能力”，不能照一条旧边按并列数量补边，须区分平台、组件和功能。“一次港口试验由运营方、承包商和检测机构参与，耗时减少18%，对照口径未说明”，应保留试验角色、18%及口径疑点；不能把它变成运营方的固定效率，或由共现造三组业务边。原文未说明分工时保留未决，已有同等含义与限定的表达无需重复建议。

给出少量具体自然语言意见：哪项含义遗漏、错配或限定不足，来源支持怎样的最小补充或替代，仍不能确认什么。必要时附已有S/K句柄，程序维护保存和进度；不用复述全包或维护技术字段。没有读完的范围明确保留，不把局部样本当作总体准确率，不以增加边数、减少TEXT或清空待定为目标。

保存本轮意见后结束；无意见也可结束。建议由原组织者确认，本轮最多一次局部修订，不发起第二轮审阅，不自动重试失败或UNKNOWN。
